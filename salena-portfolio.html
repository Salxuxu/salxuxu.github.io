UX Design Research Information Architecture

Redesigning the FP Resource Center

A comprehensive UX redesign that transformed how business coaches access and discover resources, resulting in significant improvements in user satisfaction and engagement metrics.

Role
Lead UX Designer
Scope
UX · Research · IA
Impact
+60% User Satisfaction

The Problem

Understanding the Problem

Low Discoverability
Coaches struggled to find the tools they needed because all resources were displayed in the same uniform tile format, with no hierarchy to highlight important items.
Poor Information Architecture
Resources were organized by internal departments rather than user needs. This misalignment between organizational structure and user mental models created friction in the discovery process.
Lack of Visual Hierarchy
All tiles looked nearly identical: same size, weight, and placement, producing cognitive overload. Coaches had to rely on reading every label, which slowed down navigation and reduced overall efficiency.
Inconsistent Branding & UI Patterns
The previous version lacked a cohesive design system. Icons, spacing, and typography were inconsistent, creating a disjointed experience and making the page feel dated compared to other FP digital tools.

Research & Insights

Design Challenges & Strategic Decisions

To tackle the complexity of our resource platform, we conducted a multi-pronged research approach that informed every design decision.

User Interviews

Conducted 12 in-depth interviews with coaches in the community across different experience levels and backgrounds. Key findings:

  • 78% struggled to locate resources relevant to their specific workflow
  • Users preferred task-based organization over departmental categories
  • Search functionality was underutilized due to poor discoverability

Heuristic Evaluation

Systematic review of the existing interface against Nielsen's usability heuristics revealed critical issues:

  • Lack of visibility into system status and user location
  • Inconsistent interaction patterns across sections
  • Poor error handling and validation feedback

Content Audit

Catalogued 300+ resources and mapped them against user needs, identifying redundancy and gaps in coverage.

The Solution

The Redesign

Task-Based Resource Architecture

Reorganized the FP Resource Center from a dense, uniform grid of tools into a workflow-aligned structure. Instead of forcing coaches to scan every tile, the redesign prioritizes how they actually complete tasks, making key tools easier and faster to access.

Improved Scannability & Navigation

Transformed the single-level grid into a more intuitive layout with clear labeling, visual hierarchy, and consistent spacing. Coaches can now identify tools at a glance, reducing search fatigue and improving overall usability.

Modernized High-Fidelity Interface

Designed a clean, professional, and coach-friendly interface in Figma with updated icons, typography, and interaction patterns. Translated the full design into Wix, ensuring responsive behavior across desktop and mobile.

Unified Visual System Across Platforms

Created a consistent design language that aligns with the FP brand and the newly updated FP Library. This provides a cohesive experience for coaches navigating between multiple FP digital tools.

Increased Efficiency & Positive Feedback

The refreshed layout significantly improves page clarity and reduces cognitive load. Coaches reported that the new Resource Center feels easier to use and more visually modern, with clearer pathways to the tools they rely on daily.

Measurable Impact

Results

+60%
User Satisfaction
+20%
User Engagement

Reflection

Key Takeaways

User-Centered Organization
Organizing content around user tasks rather than internal structures is critical. Mental models matter more than organizational convenience.
Accessibility as Core
Building with accessibility from the start is cheaper and more effective than retrofitting. It also benefits all users.
Design Systems Scale
Investing in a comprehensive design system pays dividends in consistency, team velocity, and long-term maintainability.
Research Validates Assumptions
User research surfaced insights that contradicted internal assumptions, leading to better design decisions and outcomes.

FP Resource Center Redesign

Redesigning the tool hub for better clarity and consistency.

Overview

Bringing Clarity to Complexity

The FP Resource Center suffered from fragmented navigation and inconsistent visual design that made it hard for users to find what they needed.

The redesign established a clear visual hierarchy, consistent component language, and intuitive pathways — reducing cognitive load and improving task completion.

Key Improvements

What Changed & Why

🎨
Visual Consistency
Unified color, typography, and component styles — eliminating the patchwork feel of the legacy design.
🗂
Clearer Navigation
Reorganized information architecture based on user mental models.
⚡
Faster Workflows
Surfaced frequently used tools at the top level with quick-access patterns for power users.
